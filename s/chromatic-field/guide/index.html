Fable 25 · Guide 08

Chromatic Field — a gallery of one, forever

A generative-art gallery framed as a white cube with a single wall. The artwork is a flow-field painting computed live: visitors regenerate it, rehang it in another palette, or download the one composition that will never occur again. The interface borrows museum conventions — wall label, edition line, serif italics — to treat browser output as an object worth keeping.

The algorithm

  • Seeded determinism: a five-digit seed feeds mulberry32; every random decision — field zoom, curl intensity, particle count, ink assignment, stroke weights — flows from it. Same seed + palette always reproduces the identical painting, which is what makes the edition line honest.
  • The field: seeded value noise sampled at each particle's position yields an angle (scaled by a per-seed "curl" factor of 1.5–5). Particles step 3.1px along it, 130 times, dragging round-capped strokes whose width and alpha decay over the walk — strokes taper like real ink running dry.
  • Weight distribution: stroke widths follow pow(rng(), 2.2) — many hairlines, few heavy ropes — the imbalance that makes it read as composition instead of noise.
  • Paper: 2,600 grain flecks under the painting, and a "margin bite" pass at the end: a thick frame-colored stroke that crops wanderers, plus a thin keyline.

Progressive rendering

The painting draws in ~33 chunks of 4 steps per animation frame, so visitors watch it self-assemble in about five seconds — the gallery's only spectacle. Under prefers-reduced-motion all 130 steps run in one frame: the finished work simply appears.

Curation, not configuration

Five fixed palettes (Kiln, Lagoon, Pressed Flowers, Graphite & Coal, Ember Storm) rather than a color picker — the difference between a gallery and a paint store. Switching palettes keeps the seed, so you can see the same composition re-inked. Titles are drawn from a fixed list by seed % titles.length, which means the title genuinely belongs to that painting.

Iteration log — three passes

Pass 1 — Build

Flow-field engine, seeded RNG, five palettes, frame + wall label, regenerate/save controls.

Pass 2 — Fine-tooth comb

Early fields produced parallel combing (scale too uniform): per-seed curl multiplier added. Particles escaping the canvas left blank corners: wraparound margins added at ±20px. Palette swap previously regenerated a new seed — wrong; it now rehangs the same seed. Save filename now embeds the seed so downloads are reproducible.

Pass 3 — Complexify & polish

Paper grain + margin-bite finishing pass; stroke alpha decay tied to step count; palette buttons became real toggles with aria-pressed and visible focus; R-key shortcut with modifier guard; label text (strokes, palette, title) updates live; reduced-motion instant render; canvas capped at 1200×1500 for crisp PNG export without tanking mobile GPUs.
