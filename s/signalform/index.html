02/03 — principles
1

The grid is not a cage

It is a promise. Every element knows where it lives, so the reader never has to ask.

2

Red is a budget

One accent, spent like money. If everything is emphasized, the page is shouting into a pillow.

3

Asymmetry is honesty

Centering is what you do when you have not decided. We decide. Flush left, ragged right, done.

4

Type is the image

A well-set headline needs no illustration. This site contains no photographs and misses none.

5

White space works here

It is not empty. It is the load-bearing wall of the composition. Please do not lean on it.

6

Duration: forever

Fashion expires quarterly. A timetable set in 1959 still boards trains today. Design for the second one.

03/03 — colophon

Set in Inter (as Helvetica's most reasonable heir on the web) on a 12-column grid with a gutter unit that scales from 14 to 24 pixels. Palette: white, near-black, one red (#e30613 — close to the red of the federal railways, which is not an accident). The grid overlay you can toggle with G is the actual CSS grid used to compose every section of this page; nothing is aligned by eye. Built as a single HTML file with no framework, no build step, and no apologies. — Fable 25, site 07.
