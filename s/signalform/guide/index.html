Fable 25 · Guide 07

signalform — the grid, exposed

An exercise in Swiss International Style done natively for the web: asymmetric 12-column composition, one accent red, flush-left everything, and typography as the only image. The signature move is the G key — it reveals the real CSS grid the page is composed on, turning the design system into the site's one piece of theater.

Why the overlay matters

Swiss modernism's central claim is that structure is visible even when the scaffolding isn't. The overlay makes the claim falsifiable: every element on the page genuinely sits on those 12 columns (grid-column: 2/7 and friends), gutters bound to a fluid unit --u: clamp(14px, 2vw, 24px) shared by every section. Nothing is aligned by eye, and you can check.

Composition notes

  • Poster hero: three-line headline — solid, hollow (-webkit-text-stroke), solid-with-red — at 900 weight and −4.5% tracking, with a single red square occupying the 12th column as counterweight.
  • Work index: tabular rows on a 10-column sub-grid; year, project, and category each own fixed columns so the ragged edges align vertically down the page. Hover reveals a red arrow — the one permitted animation, 180ms flat.
  • Principles: a bordered 3-up card grid where two of six numerals are red — spent deliberately, as principle #2 demands.
  • Colophon: set in two CSS columns, the oldest trick in editorial design, describing exactly how the page is made — the site self-documents.

Iteration log — three passes

Pass 1 — Build

Grid system, poster, work rows, principles, colophon, overlay + G-key toggle.

Pass 2 — Fine-tooth comb

The overlay initially used height:100vh inside a scrolled page — columns stopped at the fold; refit as position:fixed full-viewport so the grid rides the scroll. Work-row hover used a transform that made text shimmer: replaced with a flat background change. Mobile poster kept the red square colliding with the wrapped headline — square hidden below 760px, headline re-clamped.

Pass 3 — Complexify & polish

Added the persistent grid button (bottom-right) with aria-pressed mirroring the G key for touch users; tabular numerals on years; keyboard modifier guard so Cmd+G/Ctrl+G don't trigger it; head-note line that sets tone in nine words. Contrast audit: grey passes AA on white at the sizes used; red is never used under 700 weight.
