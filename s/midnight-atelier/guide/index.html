Fable 25 · Guide 06

Maison Minuit

A couture house whose entire collection was "never photographed" — which is the design alibi for building a fashion site with zero photography. Each of the eight looks is a textile woven from CSS gradients, lit and cropped like a garment glimpsed in a dark salon.

CSS as fabric

  • Wool crepe: a tight repeating-linear-gradient at 115° over a dark base — a literal twill weave at 11px pitch.
  • Gold lamé: a conic-gradient anchored below the frame plus one hot radial highlight, so the light seems to rake across it.
  • Moiré silk: repeating-radial-gradient rings emanating from above the crop — interference patterns without an image.
  • The gilded cage: two perpendicular 1px repeating gradients form a thread lattice.
  • Every look sits under a "veil" gradient (bottom-up black) that guarantees caption legibility no matter the fabric, and scales up 6% on hover at a couture-slow 1.2s.

The horizontal runway

  • scroll-snap-type: x mandatory with center alignment — each look presents itself, one at a time, like a model pausing.
  • A wheel listener converts vertical scrolling to horizontal motion only while the runway can still move — checked by comparing scrollLeft before/after, so the page never traps the user at either end.
  • Native touch scrolling untouched on mobile; the hint line tells desktop users the axis has rotated.

Typography & restraint

Italiana (hairline didone, all display), Cormorant Garamond italic for whispers, Jost letter-spaced small caps for apparatus. One accent color, used at two intensities. The moonbeam behind the hero is a single 1px gradient line — the cheapest element on any site in this project, and the most load-bearing.

Iteration log — three passes

Pass 1 — Build

Hero, eight CSS fabrics, runway with snap, philosophy, appointments grid, fixed nav.

Pass 2 — Fine-tooth comb

The wheel hijack originally called preventDefault() unconditionally — trapping the page when the runway hit its end; now it releases at the boundaries. Look captions failed contrast on the lamé fabric — the veil gradient was strengthened to 92% black at the base. Letter-spaced centered text was optically off-center — added matching text-indent everywhere tracking is used.

Pass 3 — Complexify & polish

Added per-city appointment cells with border seams that reflow from columns to rows on mobile; runway made keyboard-focusable (tabindex + arrow keys scroll natively); hover state moved from opacity to border-gold so reduced-motion loses nothing meaningful; scrollbar styled thin gold. Copy tightened until every caption read like a garment label, not ad copy.

Files

One self-contained index.html. Eight dresses, zero kilobytes of imagery.
