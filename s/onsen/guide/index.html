Fable 25 · Guide 01

山風 Yamakaze — Mountain Onsen

A ryokan site built on the aesthetic of ma (negative space) and sumi-e ink-wash painting. The design bet: no photography at all — the entire visual identity is generated in code, so the page feels like a painted scroll rather than a hotel brochure.

Concept spine

"The site is a hanging scroll." One continuous vertical reading, ink at the top thinning into paper, a red hanko seal as the only saturated element, and copy written as if by the innkeeper — declarative, unhurried, slightly austere.

Palette & type

#f5f1e8 washi
#1a1816 sumi
#b3402a hanko
#8c8578 stone
  • Shippori Mincho for display — a Japanese serif with genuine brush DNA.
  • Zen Kaku Gothic New at weight 300 for body — airy, wide line-height (1.9) to slow the reading pace.

Signature techniques

  • Generative ink-wash mountains: five layered ridgelines drawn on <canvas> from a tiny seeded value-noise function (~15 lines, no libraries). Each layer gets progressively darker ink and shorter amplitude — the classic atmospheric-perspective trick of sumi-e.
  • Steam simulation: soft-blurred particles with sinusoidal drift and a sine-eased opacity envelope, rising from where the baths would be.
  • Vertical typography: writing-mode: vertical-rl for the fixed poem rail and section margin-glosses — real CSS vertical text, not rotated hacks.
  • Ink-fill CTA: the "Write to us" button fills with vermillion via a scaling pseudo-element — the seal being pressed.

Iteration log — three passes

Pass 1 — Build

Structure, canvas ridgelines, steam system, all six content blocks, vertical rail, hanko SVG.

Pass 2 — Fine-tooth comb

Ridge noise was too jagged at 12px sampling — tightened to 6px steps with smoothstep interpolation. Steam opacity peaked too high (read as fog); capped at 0.10. Fixed hero text contrast where the third ridge crossed behind the romaji. Killed a horizontal overflow at 360px caused by the letter-spaced hero line (added text-indent compensation).

Pass 3 — Complexify & polish

Added the visibility-change pause so the canvas stops burning CPU in background tabs; added prefers-reduced-motion path (static painted ridges, no steam, no reveals); devicePixelRatio capped at 2; reveal animations gated behind a .js class so the page is fully readable with scripts disabled.

Files

One self-contained index.html — no build step, no dependencies beyond two Google Fonts.
