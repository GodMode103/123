Fable 25 · Guide 04

The Brutal Post

A brutalist tabloid where the design argument and the editorial content are the same joke told twice. Every visual rule the site preaches — hard corners, hard offsets, one acid color, structure as style — is also what its satirical headlines are about.

Design system

  • Type: Anton (a single ultra-condensed weight, always uppercase) against Archivo body and Space Mono for all "print apparatus" — folios, kickers, tickers, stamps.
  • Color discipline: paper #f2f2ef, ink #111, and exactly one acid #ffe600 used as reward — plus a single red postage stamp as the lone breaking of its own rule (every manifesto needs one sin).
  • The grid is visible: a 12-column CSS grid with 3px interior rules drawn by borders, cells spanning 8/4/6/4 — the layout IS the ornament. On mobile every cell drops to full-width and the vertical rules disappear.
  • Hover as ink: whole story cells invert to black; index rows shove left-padding in 3 steps (steps(3)) so even the transition feels typeset, not eased.
  • Outlined "POST": -webkit-text-stroke hollow type against solid — masthead contrast without a second color.

Details worth stealing

  • The ticker is content duplicated exactly once and translated −50% for a seamless infinite loop; it pauses on hover and is disabled entirely under prefers-reduced-motion.
  • The postage stamp hangs 1.6rem below the masthead border, rotated 6°, with a 4px hard shadow — misregistration as a design feature.
  • Faint oversized folio numbers (01–07) sit in each cell corner at 25% opacity, doing wayfinding and texture at once.

Iteration log — three passes

Pass 1 — Build

Masthead, ticker, seven-story board, manifesto strip, index table, footer.

Pass 2 — Fine-tooth comb

Masthead overflowed at 360px (letter-spacing on 14vw type) — retuned clamp and removed tracking. Acid cell's hover left yellow text on yellow: added explicit hover color override. Ticker jumped at loop point — was duplicating with different whitespace; now built from one string concatenated twice. Row hover previously moved layout via margin (janky) — switched to padding with stepped timing.

Pass 3 — Complexify & polish

Added the red stamp (rotation + hard shadow), hollow-stroke masthead word, folio numbers, hover-pause on ticker, and the "In this issue" index to give the page a second texture register. Checked all contrast pairs (yellow only ever carries black text). Reduced motion: ticker static, steps removed.

Files

One self-contained index.html. No images, no JS beyond 8 lines for the ticker loop.
